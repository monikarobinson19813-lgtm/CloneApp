# CA product strategy

## Match

We should at minimum match:
- multi-account cloning;
- simultaneous use;
- work/personal separation;
- clone data separation;
- quick switching;
- security lock;
- hidden/private instances;
- notifications;
- broad app support;
- no-root operation.

## Improve

We should improve:
- clone identity;
- status visibility;
- notification diagnostics;
- resource transparency;
- update reliability;
- compatibility transparency;
- test evidence;
- instance controls.

## Differentiate

We should differentiate with:
- Virtual + Native engine strategy;
- compatibility analyzer;
- per-instance health;
- isolation-level disclosure;
- structured compatibility matrix;
- per-instance permissions/contacts ambitions;
- recovery and update safety.

## Do not imitate

Do not imitate:
- aggressive ads;
- vague “supports every app” claims;
- misleading battery/privacy claims;
- silent compatibility failures;
- obsolete Android-target tricks;
- bypassing secure-environment declarations or integrity systems.
